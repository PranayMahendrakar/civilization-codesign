# Human-Machine Civilization Co-Design Platform
Exploring optimal human-AI arrangements for future societies.

## Features
- Capability mapping, Scenario generation
- Governance design, Economic design
- Flourishing analysis, Risk identification
- Public deliberation guides

## Usage
```bash
pip install -r requirements.txt
ollama pull llama3.2
python main.py
```
